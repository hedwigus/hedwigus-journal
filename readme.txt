A modern, minimalist editorial theme for the Hedwigus personal journal.

== Description ==

Hedwigus Journal is a lightweight WordPress theme built for a personal blog that
mixes technology, sport, hobbies and family stories. It uses a clean editorial
layout, a single accent color, fluid typography, an optional dark mode and a
responsive post grid. No page builder, no build step, no jQuery dependency on
the front end.

Features:

* Featured latest post hero on the blog front page
* Responsive post grid with category pills and reading time
* Dark mode toggle with localStorage persistence and system preference fallback
* Customizer options: accent color, dark-by-default, footer text
* Widget areas: sidebar and three footer columns
* Translation ready (text domain: hedwigus-journal)
* Accessible skip link, keyboard focus states and reduced-motion support

== Installation ==

1. Upload the `hedwigus-journal` folder to `/wp-content/themes/`.
2. In WordPress admin, go to Appearance > Themes and activate Hedwigus Journal.
3. Go to Appearance > Menus and assign a menu to the Primary and Footer locations.
4. Go to Appearance > Customize > Hedwigus Journal to set accent color and footer text.
5. Set featured images on posts; a built-in SVG placeholder is used when absent.

== Frequently Asked Questions ==

= Does this theme need a page builder? =

No. The theme uses standard WordPress blocks and template files.

= Can I change the accent color? =

Yes. Appearance > Customize > Hedwigus Journal > Accent color.

= Does dark mode work for returning visitors? =

Yes. The choice is saved in localStorage. New visitors follow the theme option
or their operating system preference.
